🕸️ Knowledge Graph Visualization

How to use:

  1. Run extraction: npm run extract <source-file> to create knowledge-graph.json
  2. (Optional) Merge graphs: npm run merge <path>
  3. (Optional) Add inferences: npm run infer <path> - inferred relationships shown with purple color
  4. Click a button below to load and visualize the graph
  5. Interact with the graph: drag nodes, zoom, click nodes for details

🔗 Advanced Features

Extract knowledge graph:
npm run extract <source-file> - extracts from text file (txt, md, etc.)

Merge graphs:
npm run merge <file> - merges with knowledge-graph.json
npm run merge <file1> <file2> - merges two files

Add inferences: npm run infer <path-to-file> (creates *-inferred.json with purple-colored inferred relationships)
